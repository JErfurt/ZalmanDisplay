# ZalmanDisplay

Открытая замена службы ZALMAN-CTM: читает датчики через LibreHardwareMonitorLib
и выводит их на USB-экран Zalman (HID `1C57:3ED1`, а также `4B8F`, `3A7F`, TDM `3ED2`/`3ED6`).

## Протокол (восстановлен из TempComm.dll)

Все пакеты — HID output report, 65 байт, `[0] = 0` (Report ID).

**Рукопожатие (0x01)** — один раз после открытия, устройство отвечает input report'ом:
`[1]=01`, `[5..6]` = случайное W, `[7..10]` случайные, `[11..12] = W ^ ((b7+b9)<<8 + b8 + b10)`,
`[63]` = XOR(i·b[1+i], i=0..59), `[64]` = Σ(i·b[1+i], i=0..62). Остальное — случайные байты.

**Данные (0x02)** — каждые ~500 мс, многобайтовые значения big-endian:

| байт | значение | байт | значение |
|---|---|---|---|
| 1 | `02` | 20 | RAM, % |
| 2 | CPU °C | 24 | диск, % |
| 3 | GPU °C | 25–26 | вентилятор, об/мин |
| 4–7 | ч, мин, с, мс/10 | 27–28 | CPU В (целое, сотые) |
| 8–9 | век, год | 29–30 | CPU Вт × 10 |
| 10–12 | месяц, день, день недели (вс=0) | 31–32 | GPU вентилятор, об/мин |
| 13 | CPU загрузка % | 33–34 | GPU В |
| 14–15 | CPU МГц | 35–36 | GPU Вт × 10 |
| 16 | GPU загрузка % | 41–44 | сеть отдача, байт/с |
| 17–18 | GPU МГц | 45–48 | сеть приём, байт/с |
| | | 49 | режим дисплея (0) |

## Установка

1. Драйвер для чтения CPU (нужен LibreHardwareMonitor ≥ 0.9.5):
   `winget install namazso.PawnIO`
2. Остановить и отключить оригинальную службу (от администратора), иначе обе будут писать в экран:
   `sc stop ZALMAN-CTM` и `sc config ZALMAN-CTM start= disabled`
3. Собрать: `dotnet publish -c Release -o C:\Tools\ZalmanDisplay`
4. Проверить: `ZalmanDisplay.exe` (запросит права администратора), `ZalmanDisplay.exe --sensors` — список датчиков.
5. Автозапуск при входе с повышенными правами:
   `schtasks /create /tn ZalmanDisplay /tr "C:\Tools\ZalmanDisplay\ZalmanDisplay.exe --quiet" /sc onlogon /rl highest`

Если какой-то показатель не тот — посмотрите имена в `--sensors` и поправьте их в `Sensors.cs`.
